## 实验协议

15 个假设在实验前写入 [plans.json](../../experiments/detection/plans.json)。仅使用开发集，通过现有本地 BHE ONNX 模型统一扫描，保留 12fps、0.03 解码下限的原始观测，再进行阈值、采样、轨迹、时间插值、多篮筐、局部运动和查看窗口对照。

所有事件与 ROI 建议都是 draft，ROI 要求实际用户确认。未知的评分不能当成提高；每轮没有提高就执行分支内的 git reset --hard，并从 work/ 恢复 TSV 历史。生产检测器不因候选数量更多而被替换。
