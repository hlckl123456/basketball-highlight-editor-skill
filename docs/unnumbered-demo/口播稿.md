# 没有号码，怎么选人和剪辑

以下为介绍 Skill 的拟用口播；本片使用 macOS Tingting AI 配音，不是用户声音。

## 没有号码，怎么选人？

如果打球的人都没穿号码球衣，我会怎么剪？这次换成公园里的一段夜场录像。有人穿便装，也有人光膀子，画面还会跟着人晃。

## 先认准这个人

我选白色宽松上衣、深红色短裤、白鞋的这位。保存两张相隔三分钟的参考图，让系统比较上衣、短裤和鞋袜，全程不用号码。这里的选人由测试操作员代做。

## 打开真实的复核页

整段录像重新提取了人形和服饰特征。这次先用覆盖窗口找回合，再整理成八段待选片段。这一轮自动结果全是不确定，我再对照参考图逐段看，不把它们当成已经认出的进球。

## 看过以后，再留片段

这五段里能对照参考图认出他，留下。另三段主要是光膀子球员持球，删掉。演示里的决定都记为测试操作员，不会冒充你已经确认过。

## 这次实际剪出来的片段

接着按时间顺序合成，保留现场声音。这就是刚才这位白衣球员的片段。原片时间、参考图、选片记录和成片，都放在仓库首页，点开就能看。
